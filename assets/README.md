# Assets fuer den ISD-Unity-Loadingscreen

Lege eigene Dateien einfach mit diesen Namen in diesen Ordner:

- `background.jpg` fuer das grosse Hintergrundbild
- `logo.png` fuer ein eigenes Logo oder imperiales Symbol
- `music.mp3` fuer optionale Hintergrundmusik

Fehlen diese Dateien, bleibt der Loadingscreen trotzdem lauffaehig und nutzt die eingebauten CSS- und Canvas-Effekte.
